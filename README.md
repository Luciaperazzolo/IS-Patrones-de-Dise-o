Desarrolo e implementaciones de Patrones de Diseño en Java

Repositorio con la implementación en Java de distintos patrones de diseño, desarrollado para la materia Ingeniería de Software. Cada patrón incluye su código funcionando, su diagrama UML de clases y una explicación de qué problema resuelve, cómo lo resuelve y cuáles son sus ventajas y desventajas.

Patrones incluidos

Creacionales: Singleton, Factory Method, Abstract Factory, Builder, Prototype, Object Pool, Dependency Injection.

Estructurales: Adapter, Bridge, Decorator, Facade, Composite, Flyweight, Proxy.

De comportamiento: Chain of Responsibility, Iterator, Memento, Mediator, Observer, State, Strategy, Template Method, Interpreter, Command, Visitor.
